# env 文件
Type: format

## Purpose

服务的 `env_file` 指向的 `.env` 文件：每行一个变量赋值，支持引用此前已定义的变量。由 dotenv 模块拥有。

## Fields
| Field | Type | Default | When invalid |
|---|---|---|---|
| 赋值行 | `KEY=VALUE`，可带前缀 `export `；`KEY` 以字母或 `_` 开头，含字母、数字、`_`、`.` | — | 缺少 `=`、变量名非法或引号未闭合时整个文件无效 |
| 注释 | `#` 开头的行；未加引号的值中，前面有空白的 `#` 开始行内注释 | — | — |
| 未加引号的值 | 到行尾，去掉首尾空白；展开变量；`\$` 得到字面 `$` | `""` | — |
| 单引号值 `'…'` | 字面量，不展开，可跨行 | — | 未闭合时文件无效 |
| 双引号值 `"…"` | 支持转义 `\n` `\r` `\t` `\"` `\\` `\$`，展开变量，可跨行 | — | 未闭合时文件无效 |

## Requirements

### Requirement: 变量展开
未加引号的值与双引号值中的 `${VAR}` 与 `$VAR` 必须展开，按已组装的变量解析：包括更低优先级的层（基础变量、全局 `[env]`、前面的 `env_file`）和同一文件中上方的行。

### Requirement: 只向前引用
引用必须只解析到该行之前已定义的变量，不能引用后面才定义的变量或服务自己的 `[env]`；未定义的变量必须展开为空字符串，并能被 `hum show` 标出。

#### Scenario: 引用后面定义的变量
- **WHEN** `.env` 第 1 行为 `URL=http://localhost:${PORT}`，第 2 行为 `PORT=8080`，且更低层没有 `PORT`
- **THEN** `URL` 的值为 `http://localhost:`，`hum show` 标出第 1 行引用了未定义的 `PORT`

### Requirement: 非引用的 `$` 保持原样
`$` 后面不是合法变量名或未闭合的 `${` 时，必须保留为字面文本。
